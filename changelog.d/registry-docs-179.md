- Documents, their revisions and comments run from the command registry on every door: `weave doc get|set|append`, `weave doc-revisions`, `weave doc-restore`, `weave comment [delete]`, `weave_get_doc`, `weave_set_doc`, `weave_doc_revisions`, `weave_doc_restore`, `weave_add_comment`, `weave_delete_comment` and `/api/entities/<id>/doc`, `/doc/revisions[/<seq>[/restore]]`, `/comments[/<id>]` dispatch from one entry each.
