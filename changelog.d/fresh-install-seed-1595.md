- A first `weave serve` on an empty data directory listens in under a second (0.6 to 0.9 s, against 4.4 to 4.8 s before on the same machine), and its docs workspace holds 6 MB instead of 39 MB. A new install's docs workspace no longer gets a copy of weave's own test suite (the Quality space) or of weave's tracker (its issues, roadmap and release notes); they live in the weave docs workspace on weave cloud, https://weave.grunion.ai/w/weave. A server whose docs workspace already holds a copy of weave's tracker keeps syncing it from `docs/development.json`, and the canonical tracker never parses the file. `node bin/weave.js quality sync --data <weave.db>` builds the Quality space when it is missing, and `quality check` reports the whole mirror as drift without writing anything (Issue #1595).
