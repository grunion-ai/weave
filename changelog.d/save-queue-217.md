- **One save queue for record edits** (Feature #217): `public/save-queue.js` holds the queue every editor will push `{ entityId, field, value }` into. It waits 600 ms after the last edit to a field, sends the writes one at a time in the order they were made, retries a lost connection or server error once, keeps an edit that still fails until the next flush, and reports how many edits are pending. The page going hidden or away (`visibilitychange`, `pagehide`, the event iOS Safari fires) sends every waiting edit at once. Gate: `test/save-queue.test.mjs`.
