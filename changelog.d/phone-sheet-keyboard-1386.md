- The New row sheet on a phone follows the keyboard instead of hiding behind it: the sheet sits on top of the software keyboard and caps its height to the page above it, so the Name field you are typing into and the Create button both stay on screen (Issue #1386). The choice-field block takes the squeeze and scrolls, keeping the title, Name and the actions in place. The keyboard's height is published as the `--wv-keyboard` custom property from the visual viewport, so any sheet can read it.
