- **The `tests` workflow checks out the full history** (Issue #558): `actions/checkout` ran at its default depth of one commit, so `test/architecture-map.test.mjs` could not ask `git merge-base --is-ancestor` whether the map's pinned revision sits behind HEAD. The object was absent, git exited non-zero, and the test read that as a dangling pin: all four matrix legs failed on every main landing from `5091c23` on, while the Gerrit gate stayed green on the same code. The same shallow checkout left `test/changelog-fragments.test.mjs` asserting nothing, because a grafted HEAD reports no parent to diff against. The checkout step now carries `fetch-depth: 0`, matching `security.yml`. Gate: `test/security/workflows.test.mjs` holds every workflow to it.
