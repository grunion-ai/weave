- `⌘Z` (Ctrl+Z) in the app undoes only a change the same tab made. Each tab keeps track of the undo entries its own writes recorded: cell edits, pastes and fills, trashes, links, uploads and any other record write sent from it. `⌘Z` steps back that tab's newest gesture only while its entries are the newest on the undo stack. Once another tab writes to the same stack (the same account's other tabs, or any browser on a server without sign-in), the tab says "Changed since, so nothing was undone" and sends nothing. A tab with no writes of its own says "Nothing to undo" and sends no request. Before, a `⌘Z` after a cell edit sent a one-step undo of whatever was newest, so it could revert a write the reader never made, with a toast naming a record they never touched. A paste's Undo button counts the paste's own rows the same way, where it used to undo a fixed number of steps whoever had written in between. The Handbook's "Making a workspace your own" guide says so (Issue #1692).
