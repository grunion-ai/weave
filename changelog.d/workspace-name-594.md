- **A new workspace gets a random adjective-animal name** (Issue #594): a fresh install used to read "workspace" in the heading, the sidebar and the breadcrumbs, because the engine seeded `Weave Workspace` and `weave serve` swapped that for the data file's basename. The seed of a fresh workspace with no name to go on now draws one adjective and one animal from two curated lists in `src/workspace-name.js` and stores the slug, so a fresh `weave serve` opens on a workspace named like `quiet-turtle`. `workspaceName()` also returns the Title Case display name, "Quiet Turtle", which the page can show once Issue #592 gives the display name its own field. Adjectives are neutral or positive; every animal is also an upstream Lucide icon name (bird, cat, dog, fish, panda, rabbit, snail, squirrel, turtle) and `ANIMALS` is exported so the workspace icon can follow the animal once those icons are vendored; `public/vendor/icons` ships none of them today. The slug passes the rename rule. A name already on the instance gets `-2`, `-3` and so on: `weave serve` checks the workspace files beside the data file, and `POST /api/workspaces` with no `name` draws a free one instead of creating a workspace called `undefined`. The Worker still names a fresh Durable Object after its route. Existing workspaces keep their names: one still carrying `Weave Workspace` takes its file's basename as before, and one named `workspace` stays `workspace`. A file someone named still names its workspace: `--data ./other.db` makes `other`, and a hub serves it at `/w/other/`; only the default data file, `workspace`, draws at random. Gate: `test/workspace-name.test.mjs`.
