- **A slash command takes the line it is typed on** (Issue #455): Text, Heading 1 to 6, Bulleted list, Numbered list, Task list and Quote used to insert a placeholder block and leave the line's words behind as body text, so `## Plan /task` ended as the heading plus a `- [ ] To do` under it. They now convert the line: the old block marker comes off, the new one goes on, and the words, their inline formatting and a nested item's indent stay. `Buy milk /task` gives `- [ ] Buy milk`, and `/text` on a heading gives a plain paragraph. The caret goes to the end of the converted line, the conversion saves through the usual debounce, and undo returns to what was typed. An empty line still gets the prefix and its placeholder. Code block, Mermaid, Table, Divider, Line break, Image, Raw HTML, the references and the format commands still insert.
