- **A filtered table rollup reads its child table once per query** (Issue #999): a Spaces rollup with `via` and a `where` listed and filtered the whole child table each time a row resolved it, so 1,000 rows that look up the same rollup ran 1,000 filter passes. A query now keeps one filtered child list per rollup field and every row reuses it; the list is dropped when the query returns, so the next query sees every write. A grid of 1,000 rows over a filtered 10,000-row rollup went from 45.2 s to 0.9 s. Gate: `test/rollup-shared-rows.test.mjs`.
