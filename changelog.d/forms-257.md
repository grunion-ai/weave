- Forms: a `Workspace/Forms` row lets someone without write access add exactly one row to one table, as themselves. Each form names its table, the fields it shows in order with labels and defaults, the fields the server fills, an on switch and a submit floor (Observer, or Anonymous when the operator sets `WEAVE_ANONYMOUS_FORMS=1`). It opens as a page at `/f/<id>`, `POST /api/forms/<id>/submit`, the `weave_form_submit` MCP tool and `weave form submit` (Feature #257).
- The bug reporter is the first form. `POST /api/bug-report` stays, as an alias that submits through the **Report a bug** form on the weave docs workspace (Feature #257).
- The weave docs workspace is built in: delete, rename and leave answer 403. Any login a workspace on the instance knows opens it as an Observer, with no invite and no account row there (Feature #257).
