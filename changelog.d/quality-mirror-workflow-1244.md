- **The tracker's Quality mirror syncs after every main tests run** (Issue #1244, Issue #1245): `.github/workflows/quality.yml` runs when the `tests` workflow finishes on a main push, red or green, checks out the commit that run tested, downloads its shard results and runs `scripts/quality-sync.mjs` against https://weave.grunion.ai/w/weave with `WEAVE_TRACKER_TOKEN`. The job fails when drift is left after the sync. It runs outside the `tests` workflow, so a tracker outage never turns main red or wakes the sheriff.
