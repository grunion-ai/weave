- **Workers run targeted tests; the poller owns the full gate** (Issue #435): CLAUDE.md, AGENTS.md and DEVELOPMENT.md told every agent to run `npm test` before each commit and to run `weave-review.sh` by hand, so parallel workers launched full suites beside the poller's gate and raced its Verified votes. The guidance now matches the gate: a worker runs the test files its change touches by name (`node scripts/test.mjs test/<name>.test.mjs`), pushes once, self-reviews and casts Code-Review +2, and the poller runs the full suite on the reviewed stack tip. Bare `node --test` is named as the trap it was: it discovers `scripts/test.mjs` as a test entry, and the runner's `NODE_TEST_CONTEXT` guard (landed with Issues #454 and #466) keeps that from starting a second suite. Documentation only; no code changes.
