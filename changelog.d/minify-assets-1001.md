- **First-party scripts and styles go out minified** (Issue #1001): the server strips indentation, comments and the spaces beside punctuation from every `.js`, `.mjs` and `.css` file under `public/` (never `public/vendor/`) once per file version, keeps the result beside the compressed copy, and compresses the minified text. The repo source stays as written and there is still no build step or dependency. Every line break stays where it was, so a stack trace or bug report line still points at the source line. A file the minifier cannot read is served as written. `app.js` drops from 665,440 to 560,178 bytes raw and from 143,025 to 135,590 bytes with Brotli; all first-party assets together drop from 280,344 to 266,560 Brotli bytes. `test/byte-budget.json` now holds the served bytes of every first-party asset after gzip and after Brotli, and refuses a raised budget that carries no reason under `raised`, the pattern `test/click-budget.json` uses.
