- **First-party scripts and styles go out minified** (Issue #1001): the server strips indentation, comments and the spaces beside punctuation from every `.js`, `.mjs` and `.css` file under `public/` (never `public/vendor/`) once per file version, keeps the result beside the compressed copy, and compresses the minified text. The repo source stays as written and there is still no build step or dependency. Every line break stays where it was, so a stack trace or bug report line still points at the source line. A file the minifier cannot read is served as written. `app.js` drops from 603,912 to 509,791 bytes raw and from 130,530 to 123,882 bytes with Brotli; all 49 first-party assets together drop from 283,453 to 269,537 Brotli bytes. Minifying `app.js` takes about 35 ms, once per file version. `test/byte-budget.json` now holds the served bytes of every first-party asset after gzip and after Brotli, and refuses a raised budget that carries no reason under `raised`, the pattern `test/click-budget.json` uses. Gates: `test/minify.test.mjs` (every first-party script keeps the same token stream on the same lines, checked with the acorn tokenizer bundled in Node), `test/byte-budget.test.mjs`.
