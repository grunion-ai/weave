- **An architecture map that fails the build when it drifts** (Feature #238): `docs/architecture/weave.architecture.html` is an interactive map of the runtime (both host adapters, the request core, the engine, both stores, the renderers, sign-in, backup, the CLI and MCP surfaces) rendered by [archify](https://github.com/tt-a1i/archify) from `weave.architecture.json`. Each of its twenty source citations links to the pinned commit on GitHub. `node scripts/architecture.mjs` re-pins and re-renders it, and each release re-pins it with the version bump. Tests: `test/architecture-map.test.mjs` (new: cited files exist, every `src/` and `bin/` module is on the map, the HTML matches the JSON and its revision, the pin is in the branch history).
