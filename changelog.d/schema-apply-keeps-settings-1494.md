- **A schema document keeps every field setting it describes** (Issues #1494, #1495, #1496, #1497, #1498): `applySchema` now carries a text field's literal setting, a toggle's on and off labels and a credential field's keystore and pair parts, so `applySchema(describeSchema(x))` rebuilds them instead of falling back to the defaults. An edit to a text literal, a toggle label, an avatar shape or a cell colour in a schema document now plans an update and lands; before, it applied as a no-op. Gate: `test/schema-mirror.test.mjs`.
