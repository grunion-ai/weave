- **Space and table writes run from the command registry** (Feature #179): create, update, delete and restore for spaces, and create, update, move, duplicate, delete and restore for tables are one entry each in `src/commands.js` for the CLI, MCP and the API. The doors now answer alike: a space or table delete answers `{ok, space|table, deleted, hard}` everywhere, and a space update answers the space with its members on every door. `weave table move` refuses a move with no destination space the way the API did.
