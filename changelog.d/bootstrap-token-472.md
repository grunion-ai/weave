- `weave serve` refuses to bind an address other than loopback while the hub root has no account, since everyone who reached the port would have been an architect. `WEAVE_BOOTSTRAP_TOKEN`, a long random string, lets that first boot start: `serve` accepts it as an architect Bearer token until the first account exists, then it answers 401. The CLI help, the Environment reference, the Railway and Docker guides, the `Dockerfile`, `compose.yaml` and `fly.toml` name it (Issue #472).
