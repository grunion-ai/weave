- **Users system table** (Feature #318, Issue #852): every account and pending invite is now a row of Workspace/Users, pinned in the sidebar under Workflows. A new row with an Email invites that person at its Role and answers with the one-time link; a new row with Kind Agent makes an agent account and answers with its token once. Editing Role or Name changes the account, deleting the row revokes the invite or deletes the account, and any table can relate to Users. Only an architect writes Users rows, and no row, query, export or MCP answer carries a token, session or invite hash.
