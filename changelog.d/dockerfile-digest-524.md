- **The container image is pinned by digest and runs on code it cannot change** (Issue #524): `FROM` names `node:22.23.2-slim` by its `sha256` digest, so a build gets the bytes that were reviewed rather than whatever the tag points at that day; the application tree is copied as root and the `node` user that runs it can only read it; `.dockerignore` matches `*.db`, `files/`, `node_modules` and the other state patterns at every depth instead of the repository root alone. `test/security/dockerfile-hygiene.test.mjs` guards all three.
