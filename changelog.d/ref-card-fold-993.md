- **The reference cards fold** (Issue #993): the References and Referenced by cards in a record's side column had no control, so a long reference list could not be put away the way Activity and comments can. Each card now carries a head caret that hides its chips and keeps the `References · N` count in view. The fold is remembered per table and per card in the same `localStorage` store document sections use, so every record of that table opens the card the same way. Gate: `test/references-fold-browser.test.mjs`.
