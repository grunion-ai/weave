- **A query can name a saved view** (Issue #839): `weave_query {view}`, `weave query <table> --view <name>` and `POST /api/tables/:table/query {view}` take a table view by id or name and answer the rows that view shows. The engine's new `viewQuery(table, view)` is the one server-side translator: each saved filter becomes `[field, 'in', names]` (a toggle's on and off names become `true` and `false`, as the grid sends them), ANDed with the caller's `where`, and the view's sort and search apply unless the caller passes its own. An unknown view answers not-found with the views the table has. Gate: `test/query-view.test.mjs` (the translation, the merge rules, and the same fixture through MCP, CLI and REST).
