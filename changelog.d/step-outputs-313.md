- **Every automation action yields an output, and later actions read it** (Feature #313): `set-field` yields `{field, value}`, `append-doc` `{field, text}`, `add-comment` `{id, text}`, `upsert-row` `{id, publicId, name, created}` and `webhook` `{url, sent}`. A later action reads an earlier one as `{{steps.1.publicId}}` in its text, in a `set-field` string value (which now takes the same `{{…}}` templates as text actions) or as `steps.1.name` in an `upsert-row` source path, so "open the account, then write its number back on the request" is a three-action rule. A step not yet run, or a path it has not got, reads empty. The `automation-ran` activity entry carries each row's outputs under `steps`, in action order. Gate: `test/automation-steps.test.mjs`.
