- **The Views list: handles, row buttons, inline naming, and Standard** (fixes Issue #443): the View dropdown has no right-click, context menu or double-click rename any more. Every view row shows its drag handle; a drag by it, with a mouse or a finger, or Alt+Up / Alt+Down on a focused row reorders the list, with the square-ended insertion line the Fields popover uses. Rename, Duplicate and a hold-to-delete are row buttons that show on hover and on keyboard focus, and Rename edits the name in place. **+ Add view** no longer opens a modal: it appends a row inside the open dropdown with a focused, selected name, the next free `View 2`, `View 3`, …; Enter or a click away creates the view and opens it with the dropdown still open, and Escape drops the row. Duplicate uses the same row under its source, offered as `<name> 2`. The first view's row reads **Opens first**, and the caption moves with whichever view is dragged to the top. The first view is named **Standard**: a new table's is born with the name, and a view still called `Default` is renamed once when its workspace opens (its Workspace/Views row too), unless the table already has a Standard; a view named Default afterwards keeps its name. The View button, the Handbook, AGENTS.md and the `weave_table_view` description say Standard. Tests: `test/view-standard-name.test.mjs` (new), `test/table-views-browser.test.mjs` (rewritten for the list), and the view suites that addressed the first view by name.
