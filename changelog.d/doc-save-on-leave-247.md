- **A document typed on a phone is saved when you leave it** (Issue #247): the editor handed its text over 800ms after the last keystroke and saved it 600ms later, and the leaving flush wrote only what had already been handed over. A switch to another app, a locked phone, Back, a closed entity panel or a reload inside that 1.4s lost the last words, and a backgrounded tab lost them every time because nothing flushed on a hide. Leaving a Description or any other markdown document field now reads the editor as it stands and writes it at once: on tapping outside the field, on Back and other route changes, on closing the panel, on `pagehide`, and when the tab is hidden. Writes from a hidden tab ride `keepalive` (a body over 60KB goes as a plain fetch, which the browser would otherwise refuse), so the save survives the tab being frozen. Editing stays in the rendered view and there is still no Save button.
