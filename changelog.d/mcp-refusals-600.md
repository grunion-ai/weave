- **Row writes refuse a missing `values` by name** (Issue #600): `weave_update_entity` sent without `values`, or with `fields` where `values` belongs, used to throw a raw `Cannot convert undefined or null to object`. It now answers `values is required: a map of field name to value` and names each key the tool does not take (`unknown 'fields', 'db'`). `weave_create_entity` refuses an unknown key the same way, so `{db, fields: {...}}` no longer leaves an empty row behind. Gate: `test/mcp-refusals.test.mjs`.
- **A Sort cell takes `-Date` and JSON** (Issue #626): a `Sort` written on a `Workspace/Views` or `Workspace/Tables` row as `-Date`, `+Date`, `[{"field":"Date","dir":"desc"}]` (as text or a list) or `["-Date"]` now lands, and the row reads back as `Date desc`. A Sort naming a field the table lacks, or JSON that does not parse, is refused with `Sort reads 'Field asc|desc, Field2 asc|desc', e.g. 'Date desc'`. The primer and the AGENTS.md pitfall table say so. Gate: `test/mcp-refusals.test.mjs`, `test/agent-front-door.test.mjs`.
