- Permanent delete moved to a new Settings page, opened from the personal menu (the ⋯ beside your name at the foot of the sidebar). Each trashed row or share page there has a Delete forever button; you type the item's name to arm the hold, then hold it until it fills. The Trash page now only restores. Workspace delete is back in the same place, behind the same typed name and hold, and moves the workspace to the trash, where Restore brings it back. Only a caller the server lets purge (an editor or architect) sees Delete forever, and only an architect on the hub root sees workspace delete: `GET /api/trash` now returns `purge`, and the `deletable` field on `GET /api/workspaces` now depends on the caller's rights.
