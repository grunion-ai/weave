- **Links in a previewed HTML file open in a new tab** (Issue #1475): a plain link inside an attached HTML file navigated the preview frame itself, the target site refused to be framed, and the panel went white. The `?view` route now puts `<base target="_blank">` after the doctype, so every link opens a new tab and the panel keeps the file. Links to a spot on the same page (`#section`, `#`) and `javascript:` links still run in place, and a page that sets its own `<base>` keeps it. Gates: `test/attachments-preview.test.mjs`, `test/html-preview-links-browser.test.mjs`.
