- **AVIF photos show on board cards and open in place** (Issue #1212): an AVIF upload was served as a download (`application/octet-stream`) and the board's picture rule skipped it, so a Shopping List card with an `.avif` photo drew the empty cover. The file route now recognises AVIF bytes and serves them inline as `image/avif`, and a board takes an AVIF file as a cover picture. Gates: `test/attachments-preview.test.mjs`, `test/board-layout.test.mjs`.
