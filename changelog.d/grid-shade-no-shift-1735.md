- **Opening a wide table no longer shifts its layout** (Issue #1735): the trailing-edge shade turned `.card.table-wrap` into a grid only once the first paint had measured an overflow, so a desktop table settled with a visible jump and the `open-table|desktop|cls` reading sat at 0.139 against a 0.01 budget. The wrap is a grid from its first paint, with a `minmax(max-content, 1fr)` column that holds the same width in both states, and the shade fades in on `wv-overflow-x` instead of arriving with a new layout.
