- **Every crumb wears its icon, and the current crumb names the row** (Issues #669, #673): the workspace crumb shows the workspace's mark as the rail draws it, space and table crumbs show the icons the sidebar draws, and a row crumb shows its table's icon, a muted monospace `#id` and the Name, on the table page, the entity page and in the dock. Row crumbs no longer have table crumbs between them: the icon carries a hop into another table and the tooltip names it. The dock's crumb starts at the row, since the table panel beside it already names the table. One renderer (`crumbPath` in `public/app.js`) draws every crumb row; `entityCrumbs` and `dockCrumbs` in `public/breadcrumbs.js` return the crumb model.
