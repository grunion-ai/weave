- **Document links and images keep only safe targets** (Issue #490): `src/markdown.js` wrote a link or image target into `href` or `src` without checking its scheme, so `[x](javascript:…)` in a document ran script on the workspace origin when clicked in `doc.html`, an export, or anywhere the app shows `/api/markdown` output. A target is now written only when it is relative, an in-page or in-app anchor, or uses `http`, `https` or `mailto`; image sources also take inline PNG, JPEG, GIF and WebP data. The check decodes entities, drops control characters and whitespace and folds case before it reads the scheme, and covers entity reference chips too. Any other target renders its text with no anchor. Raw HTML blocks are unchanged. Gate: `test/security/markdown-schemes.test.mjs`.
