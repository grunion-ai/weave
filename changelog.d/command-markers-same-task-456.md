- **A Raw HTML or reference command lands on the keypress** (Issue #456): `/raw html` used to paint its `raw-html` marker into the document for 821ms before the block appeared, `/entity`, `/link table` and `/space` opened their picker about 800ms after Enter, and the first undo afterwards brought the marker back and reopened the picker. Both rode Vditor's `undoDelay` timer, which records the undo state in the same callback. The MutationObserver Issue #455 added for block markers now watches every command marker and applies it in the task the marker lands in (`watchCommandMarkers` and `applyCommandMarkers` in `public/app.js`), so the marker is never painted and never reaches the undo stack; the editor's `input` handler keeps the same checks as the net under it. Tests in `test/slash-commands.test.mjs` and `test/slash-convert-line.test.mjs`.
