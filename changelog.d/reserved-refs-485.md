- **`__proto__`, `constructor` and `prototype` find nothing** (Issue #485): the engine's lookups indexed plain objects by the caller's ref, so these three resolved to `Object.prototype` or `Object`, and the write verb that followed (`updateSpace`, `shareView`, `grantKey` and others) set properties on every object in the process. Every id and name lookup (spaces, tables, fields, entities, views, automations, accounts, keys) now reads own properties only, the three names are refused when a space, table, field, view, account or key is created or renamed, and an import keyed by one is refused. Gate: `test/security/proto-refs.test.mjs`.
