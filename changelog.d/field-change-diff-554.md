- **A field change's Activity page reads as the change, not as JSON** (Issue #554): recolouring one option printed the field's whole definition twice as one 319-character JSON line each, with the one difference (`"hue":"teal"` against `"hue":"green"`) buried in the fourth wrapped line. The page now shows each changed setting in the field's own terms: an option or a workflow state as its chip before and after, marked Added, Removed, Renamed, Recoloured, Icon changed, Category changed or Moved, with the rest counted as "3 unchanged"; a formula as its text with the inserted and deleted words marked; name, type, format, default (a select default by option name) and the other settings as plain before and after values. The two definitions sit folded under **Show definitions**, pretty-printed with a two-space indent, and Roll back stays where it was. The diff is `public/field-diff-core.js`, pure and tested in node (`test/field-diff-core.test.mjs`); `test/field-config-undo-browser.test.mjs` checks a recolour reads as the option's two chips in both themes.
