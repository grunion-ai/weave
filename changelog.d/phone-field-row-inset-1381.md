- **One left edge for every phone field value** (Issue #1381): on the phone record page the Due date sat 7 px right of the chips beside it, because a date field puts its input inside a `.date-cell` wrapper and so missed the inset every other value kind carries. One rule now names each value kind that holds an input, so numbers, dates, plain text and chips all start at the same edge. The row also carries its own 6 px of block padding against a 56 px floor, so a 44 px input no longer fills its row to the hairline and a focused input keeps its ring clear of the divider instead of growing onto it.
