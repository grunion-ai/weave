- `POST /api/tables/:db/entities` takes `dedupe: true`, so a filer can ask before it files. If a live row of that table already has the new row's name, ignoring case and surrounding spaces, the create answers 409 with code `conflict` and that row under `entity`, whatever its state, Fixed rows included, and nothing is created. A row in the trash does not count. With no such row the create goes ahead as before, and a create without `dedupe` is unchanged. A `dedupe` that is not true or false, or a `dedupe: true` with no name to match, answers 400 (Feature #372).
