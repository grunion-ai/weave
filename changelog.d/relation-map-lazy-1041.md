- **The relation map loads where it is drawn** (Issue #1041): `relationMapView`, `mapCard`, `showMap` and `mapAutomations` moved out of `public/app.js` into `public/relation-map.js`, and `public/relmap-layout.js` is no longer a script tag on every page. The workspace home, an opened space overview, the phone space launcher and `#/map` fetch both files on first draw; a table, board or record page fetches neither. Both files are named in a `#lazy-assets` template in `public/index.html`, so `lazyScript` loads them by their versioned names and a warm home load revalidates neither. A failed fetch shows "The relation map did not load" and the rest of the page paints. Gate: `test/relation-map-lazy-browser.test.mjs`.
