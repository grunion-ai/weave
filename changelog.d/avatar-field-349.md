- **Avatar field type: a row's face on its chip, card, crumb and header** (Feature #349, supersedes Feature #139): a new `avatar` field holds one image file from the row, or nothing, in which case the row shows its initials on a colour drawn from its name. `shape` is `round` (default, people and agents) or `square` (organisations, logos), and a table holds one. A table with an avatar field puts the face first in the row's chip inside its link, first in the card's head, in the crumb in place of the row mark, beside the name on the row's page (click or drop an image to change it), in relation chips that point at the row and beside the ⌘K hit. A table without one renders as before. System/Users is minted with an Avatar field, and an agent account wears a small badge. The `PERSON_TABLE` name regex that guessed people from table names is gone. An avatar never takes an inventory icon: an icon says what kind of row, an avatar says which row. Gates: `test/avatar-field.test.mjs`, `test/chip-renderer.test.mjs`, `test/breadcrumbs.test.mjs`. The upload takes PNG, JPEG, GIF or WebP; an SVG is refused because weave serves uploaded SVGs as downloads.
