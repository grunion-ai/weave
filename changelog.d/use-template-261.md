- **Use Template** (Feature #261): any space can be a template, marked by the **Template** box on its Workspace/Spaces row or `template: true` on `weave_update_space`, `weave space update --template true` and `PATCH /api/spaces/:space`. A template space's page shows **Use template**, whose dialog copies the space's schema, never its rows, into another workspace of the hub under a name you choose: tables, fields and their config, option colours and icons, workflow states, views, widths, field order, hidden fields, filters, sorting, the term, the icons and the space rollups over its tables. A relation to a table outside the space stays behind and the answer names it under `skipped`, with every lookup, rollup and formula that reads through it. A name the target already holds is refused (409), and building in a workspace needs an architect there (403). The engine verb is `useTemplate(space, target, { name })` over the pure `templateDoc()`, and `applySchema` takes `partial: true` so a one-space document leaves the target's other spaces and space rollups alone. Doors: `GET /api/templates` and `POST /api/spaces/:space/use {workspace, name?}`, `weave template list` and `weave template use <space> --into <other.db> [--name N]`, and the MCP tools `weave_template_list` and `weave_template_use` (HTTP only; a stdio server holds one workspace), the `template.list` and `template.apply` verbs Feature #244 still owed. Gates: `test/use-template.test.mjs` (a source space wearing every costume, copied into a fresh workspace, describes exactly as its `templateDoc`), `test/use-template-routes.test.mjs`, `test/use-template-browser.test.mjs`.
- **A schema document applies whole into a fresh workspace** (Issues #639, #640, #641, #642): `applySchema` creates a new table's relations, lookups, rollups and formulas after every table in the document exists, where it used to stop at the first relation with "Use addRelation() to create relation fields"; it reads a relation's cardinality from both ends, so many-to-many and one-to-one stay what they were; it keeps select option icons on a create and through an options edit; and it applies `bodyBlocks`, the entity page's block order. Gate: `test/schema-roundtrip.test.mjs`.
