- weave can now use a **System › Integrations** key without handing it out: the engine's `integrationFetch` sends one https request to the row's Host with the key in the Authorization header. It refuses every other host, port and scheme, a caller-set Authorization, Proxy-Authorization or Cookie header and a row that is Off or has no key, before anything is sent, and never follows a redirect. Each call stamps Last Used and writes a `key-used` audit entry with the integration, host, method, path and status; a key the host echoes back is redacted from the answer. Nothing calls it from outside the engine yet; Feature #310's http-request action will. (Feature #339)
