- **Opening a table in Safari no longer records an error** (Issue #464): the grid's fit observer toggled `wv-grid-scroll` on the wrap it watches, and that class caps the wrap's height, so the callback resized what it observed and WebKit raised a window `error`, "ResizeObserver loop completed with undelivered notifications.", on every table a Safari reader opened. The in-app recorder listens on `error`, so a report filed from Safari counted an error the reader never caused. The observer's body now runs in the next frame, which also collapses a first draw's repeat callbacks into one pass.
