- **A workspace file total, and a limit an operator can set** (Issue #1431): every workspace in a data directory writes its attachment blobs to one `files/` folder, so one workspace could fill the volume and leave every other workspace failing uploads and writes. The engine now counts the attachment bytes a workspace holds, rebuilt from the workspace on load and moved by every attach and delete, and `/api/health` carries it as `fileBytes` beside `fileLimitBytes`. Set `WEAVE_WORKSPACE_FILE_MAX_MB` and an attach that would take a workspace past that figure is refused with 507 `storage-full` and a message naming what the workspace holds and what it may hold; unset, weave counts and refuses nothing.
