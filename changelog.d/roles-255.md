- **Roles are Observer, Editor and Architect** (Feature #255): `reader`, `writer` and `admin` are renamed `observer`, `editor` and `architect`, Kyle's three-level model. An observer now comments: it may post a comment, which carries its own account name whatever the body says, and delete a comment it made; every other write is still a 403. An editor creates, edits and deletes rows and comments and never structure, as a writer did; an architect does everything an admin did. Every open rewrites an old name stored on an account, so every `wv_` token and session keeps working, and the routes read an old name still on a row as the new one. `weave account create --role`, `POST /api/accounts` and MCP `weave_accounts create` default to `editor` and still take the old names for one release, answering with a `note` that names the new one. "Free", "paid seat" and "paid" are labels only (Feature #256 records that seats and billing are not built). Gates: `test/roles.test.mjs`.
