- **Sign out everywhere sends one request** (Issue #719): the account menu's Sign out everywhere posted `/api/auth/logout` once per workspace in the rail under `Promise.allSettled`, so a slow or refusing workspace left the sweep half done while the page still landed on the signed-out sign-in page, and the per-workspace calls never cleared the start cookie or the rail. It now posts `/api/auth/logout?everywhere=1` once (Feature #280), which ends every session the browser holds and clears the start cookie and the rail in one response. The per-workspace loop runs only when that call answers 404, for a server older than Feature #280.
