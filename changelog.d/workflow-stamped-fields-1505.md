- **Workflow stamped fields refuse a caller's write** (Issue #1505): `When`, `Then` and `Last Run` on a rule are the engine's to write. A write to one of them through the API, MCP or the CLI is refused with the invalid code and a message naming the field, instead of being accepted and then replaced at the next settle. A Workflows row whose Script is not a rule is still ordinary data and takes those values by hand.
