- The browser shards of the `pr` and `tests` workflows start from the Playwright 1.62.1 image (`mcr.microsoft.com/playwright:v1.62.1-noble`), pinned by its `@sha256` digest, so no shard installs Chromium, WebKit or their system packages from apt at test time. The container runs as the runner's uid 1001 with `--ipc=host` and `--init`, unit shards stay on the bare runner, and each shard now takes the plan job's durations through `actions/download-artifact`, since the image carries no GitHub CLI. `test/security/workflow-images.test.mjs` refuses a container or service image in any workflow that is not pinned by digest, and `test/ci-browser-image.test.mjs` refuses an image whose Playwright release differs from the driver in `.github/test-tools` (Feature #368).
