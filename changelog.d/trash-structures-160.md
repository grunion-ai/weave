- Trash names each line by what it holds: a trashed space reads Space, a trashed table reads Table in its space, and a record reads Record in its table, where the column used to show the registry table behind it (System/Spaces, System/Tables). Restore on a space or table line brings it back to the sidebar in one click, and a table inside a trashed space says to restore the space first. The table and space menus gain Open trash, beside the Trash row in the sidebar (Feature #160).
