- A workflow webhook action takes `signWith`, the name of a keystore credential, and signs each delivery: `X-Weave-Signature` carries the hex HMAC-SHA256 of `<X-Weave-Timestamp>.<raw body>`, beside an `X-Weave-Delivery` uuid. A receiver can now tell weave from anyone else without a token hidden in the url. The credential value stays in the keystore, so the Script, the Workflows row, the export and the backup hold the name alone. A rule that names no credential posts exactly what it posted before; a rule whose credential the keystore does not hold sends nothing and reads Failed, since weave never falls back to an unsigned delivery. The verify recipe is in the Automations guide. (Issue #951)
