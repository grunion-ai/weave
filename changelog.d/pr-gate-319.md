- **Pull requests run their tests on GitHub-hosted runners before auto-merge** (Feature #319): the new `pr` workflow runs every unit file in three shards and the browser tests the diff maps to (a changed browser test, a test named for the changed module, a test whose source cites the changed file), plus a fixed smoke set, in about twenty files a shard and four shards at most. `PR gate` succeeds only when every shard ran and passed at the exact commit, and it is now a required check on main beside `Dev gate`. A newer push cancels the superseded run. Agents no longer wait on the shared local test manager to land; the full suite still runs on every main push. Gate: `test/ci-test.test.mjs`.
