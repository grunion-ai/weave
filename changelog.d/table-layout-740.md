- **A view saved as Table stays Table** (Issue #740): the engine used to delete `layout` when it was set to `table`, so a view someone switched to Table read back exactly like one nobody had touched, and a phone could never tell them apart. `layout` now has three states: `list`, `table`, and unset. `weave_table_view`, `weave table view --layout`, REST and the System/Views `Layout` cell all keep `table`; `null` (or an empty `Layout` cell) clears the choice, and Reset view clears it too. Gate: `test/list-layout.test.mjs` (a Table choice reads back as `table`, survives `describeSchema`, and `null` clears it).
