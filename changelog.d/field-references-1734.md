- Renaming a field rewrites the table rollup filters and the relation subtables (columns, filter and sort) that name it, through a relation path too, and lists them on the rename's Activity entry beside the formulas; rolling the rename back puts them back. A new name holding `.` is refused while a filter path names the field (Issue #1734).
- Deleting a field is refused while a formula, a table rollup filter or a relation subtable still reads it, as it already was for lookups and rollups, and the refusal names each reader. A schema apply that drops a field together with its readers still goes through (Issue #1738).
