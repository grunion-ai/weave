- **Backups under the keychain store carry key names, never values** (Feature #213): when credentials live in the macOS keychain, `weave backup` writes a `keys.json` entry listing the key names and no `keystore.json`, and the summary line says so. `weave restore` reads that list and names every credential whose value this machine's key store does not hold, so each can be set again with `weave key set`. Under the file store a backup still carries `keystore.json` as before. With no `keystore.key` on disk, an encrypted or `weave://` backup now needs `WEAVE_BACKUP_PASSPHRASE` or `--passphrase-env`. `WEAVE_KEYSTORE=keychain` no longer reads as a key file path. Gate: `test/backup-keychain.test.mjs` greps the archive for a known test value and finds nothing.
