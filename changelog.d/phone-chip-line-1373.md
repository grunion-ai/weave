- Every value on a phone list row's chip line now draws at the select chips' size. A plain number or a date rested as an input, which the iOS no-zoom floor (Issue #724) sets to 16px, so it read larger than the 13px chips beside it; on the phone list, where values are edited from a sheet and never in the row, they now rest as text, as a text value has since PR #646. A formula that returns text or a number draws as the slate chip a select value uses instead of as bare text. When a multiselect or relation hides some of its values, its own `+N` folds into the row's single counter, so a line never reads `+1 +2`. (Issue #1372, Issue #1373, Issue #1388)
