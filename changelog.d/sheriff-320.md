- **A red main gets a sheriff** (Feature #320): when a main push `tests` run fails, the new `sheriff` workflow reruns its failed jobs once and logs a green rerun as a flake. A second red bisects the commits since the last green `CI gate` by dispatching `tests` on midpoint commits (the `tests` workflow takes a `ref` input for this), at most four runs, then opens a squash auto-merge revert PR naming the failing tests, the run links and the original PR, comments on that PR, files an Issue row and writes one alert line. It never reverts a revert, never acts on the same culprit twice and never pushes to main. Gate: `test/sheriff.test.mjs`.
