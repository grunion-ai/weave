- **`weave key migrate --to keychain` and `--to file`** (Feature #213): moves every credential, its owner and its sharing between `keystore.json` and the macOS keychain, reads each value back from the new store, and only then deletes the old one (`keystore.json` and `keystore.key`, or every `weave:` keychain item). A value that does not read back stops the move with nothing deleted. A move weave would not follow is refused before anything moves: on a Mac the default `~/.weave/keystore.json` follows the move by itself, and any other path needs `WEAVE_KEYSTORE=keychain` or `WEAVE_KEYSTORE=file` set for the move and for every weave that reads the keys. The move is a local operator act: MCP refuses it, and HTTP refuses an account. A running server picks the store on every key read, so it follows a move made from the CLI without a restart. Gate: `test/key-migrate.test.mjs`.
