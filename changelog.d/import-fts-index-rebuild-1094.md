- Importing a workspace into SQLite scales with its row count: 50,000 rows land in 0.9 s where they took 291 s. A full save deleted one row at a time from `entities_fts`, whose `id` column is UNINDEXED, so each delete scanned the whole index and the write path cost grew with the square of the row count. It now clears the index once and inserts every live row, and `Store.save` prepares its four row statements once per save instead of once per row (Issue #1094).
