- Search and undo run from the command registry on every door: `weave search`, `weave undo [list]`, `weave_search`, `weave_undo`, `GET /api/search`, `GET /api/undo` and `POST /api/undo` dispatch from one entry each. Each door keeps its own answer: the CLI search still runs the record search, MCP and HTTP the universal one; `weave_undo {list}` still answers `{history}`, the CLI and HTTP the bare list. `weave undo list` is new and lists like `weave undo --list` (Feature #179).
