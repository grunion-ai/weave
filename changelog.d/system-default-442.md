- **One system default for Reset view and New view; deleted rows and the Σ row saved per view** (fixes Issue #442): `systemDefault(db)` is the one answer to "a fresh view": every regular field in schema order with the table's default system columns, no filter, sort, search, widths or frozen columns, no deleted rows, no Σ rollup row, Comfortable. Reset view writes it into the view on screen and clears the search; + Add view creates the new view from it, so the two cannot drift. Deleted rows and the Σ row are now the view's, beside filters, fields, sort and density: two view keys, `deleted` (true shows the trashed rows in place) and `rollups` (true draws the Σ row, false hides it, null follows the table's older `hideRollups`, so no grid changes on the upgrade), on `weave_table_view`, `weave table view --deleted on|off --rollups on|off|table`, `/api/tables/:t/views/:v`, the schema document and the Workspace/Views row's new **Show Deleted** and **Rollup Row** columns. The Fields popover's Rows boxes save into the current view, and a switch to another view shows that view's own.
