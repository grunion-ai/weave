- **No em dashes in release notes** (Issue #722): CHANGELOG.md body prose carried 156 U+2014 characters that the house prose rule bans, and the GitHub Release body copies them. Each one is rewritten with the comma, colon, parentheses or hyphen its own sentence wants, read line by line. `test/changelog-fragments.test.mjs` now pins the whole file instead of the version headings, and `fragmentGuard` refuses a commit that adds or edits a `changelog.d/` fragment carrying U+2014, so the character cannot come back through the door that let it in. `changelogGuard` lets a CHANGELOG.md line be rewritten to drop the character without a version bump, and nothing else.
