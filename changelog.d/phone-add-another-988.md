- **On a phone, Create keeps the New row sheet open for the next one** (Issue #988, Net Tasks #125): Create, or Return in the Name field, used to wait for the write, close the sheet and open the new row, so a second row took four taps and a wait. On a phone the name and choices now clear at once, the cursor stays in Name with the keyboard up, the write runs in the background and a toast names the new row with an **Open** action. A refused write puts the name back and shows the reason. **All fields** still creates the row and opens it, and the desktop sheet is unchanged. Gate: `test/phone-new-row-sheet-browser.test.mjs`.
