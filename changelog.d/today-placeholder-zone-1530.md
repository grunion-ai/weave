- `{{Today}}` and `{{Today:iso}}` in an automation name the day on the clock of the run. A schedule rule reads it in the rule's own `zone`; any other rule reads it in the zone of the person or agent whose write fired it, taken from the `X-Weave-Zone` header, which a `PATCH` to a record and the state route now carry into the rule as a create already did. With neither, the day stays UTC. A rule that stamped a date field in the evening in the Americas used to write tomorrow (Issue #1530).
