- Every MCP tool refuses an argument its input schema does not name, before it runs, and the error names the arguments the tool takes. A misspelled `where` on `weave_query` used to answer every row as if it had matched, with no error; it now answers `weave_query takes db, where, sort, ...; unknown 'filter'` as an `invalid` error (`-32602`). `weave_call` refuses a stray key of its own the same way, and a `weave_build` spec sent bare refuses a key that is neither a spec key nor `dryRun` or `skipExistingRows`, so a misspelled `dryrun` writes nothing (Issue #1559).
- The single verbs take the spellings `weave_build` teaches. `weave_add_relation` takes `to` for `targetDb`, or a list of tables for `targetDbs`; `weave_add_field` and `weave_update_field` move the config keys sent beside `type` into `config`; `weave_query` reads `sort: "Value desc"`, `"-Value"`, a list of those, or one `{field, dir}` (Issue #1568).
