- **A malformed percent-escape in the path answers 400 instead of ending the server** (Issue #484): the node listener called `decodeURIComponent` on the path with nothing around it, so a request like `GET /%E0%A4%A` was an unhandled rejection and the process exited. The listener's whole body is now guarded: a path that will not decode is a 400, any other throw is a 500 with the detail in the log, and the next request is served. Gate: `test/security/malformed-path.test.mjs`.
