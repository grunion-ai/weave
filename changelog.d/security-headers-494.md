- **Every response carries security headers** (Issue #494): none were sent. Every answer now has `X-Content-Type-Options: nosniff` and `Referrer-Policy: same-origin`. HTML answers add `Content-Security-Policy: frame-ancestors 'self'`, so another site cannot frame weave, and a `Content-Security-Policy-Report-Only` policy naming the target state (no inline script or style), which is reported and not enforced yet. `Strict-Transport-Security: max-age=31536000` goes out only on a request that arrived over https, read through `WEAVE_TRUST_PROXY` and `X-Forwarded-Proto`. The new `WEAVE_FRAME_ANCESTORS` (comma-separated origins) lets a demo page on another origin frame weave. weave's own deck, document and file previews frame same-origin pages and still load.
