- The sheriff keeps one standing Issue row per detector. A test that turns main red again lands on its `Error: <test> fails on main` row, and a shard timeout on `Error: tests shards time out on main`, instead of a new row per PR or commit: the row takes the new evidence, an In Progress row keeps its state, and a Fixed one reopens. Every row the sheriff creates carries Area and Symptom. The Area comes from the paths the convicted commits changed, then from the failing test files; a red that no commit explains is a Gate row, as every flake row is. Creates ask the tracker to dedupe, so a run that races another lands on the row the other filed. A dry run no longer appends its evidence to an open incident row it finds, and it reads on without a tracker token (Feature #372, Issue #1791).
