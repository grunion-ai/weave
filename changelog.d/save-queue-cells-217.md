- **Grid cells and record fields save through the save queue** (Feature #217): every edit made in a table cell or a field on the record page or dock goes into the save queue instead of its own PATCH. Four quick edits show one clock in the header and no toast, land as four PATCHes in the order they were made, then the tick. With the server unreachable the edit is retried once, the cell keeps the typed text, the error toast still says "was not saved", the glyph turns red, and a tap on it once the server answers lands the edit. The page going hidden with a field still focused, as iOS leaves it, commits that field and sends it within a second. Cmd-Z and Undo send any waiting edit before they undo, so they undo the edit just made, as before; the activity log and the "changed first" conflict toast read as before.
