- The AGENTS.md repo map now names every file in `bin/`, `src/` and `public/`, 129 entries in 39 rows, each row saying what lives there and, where one exists, which doc to read before changing it (SECURITY.md for access and sign-in, docs/menu-contract.md for menus, docs/grid.md for the grid's pure cores). A new region index, `docs/regions.md`, cuts `public/app.js` and `src/engine.js` into regions of at most 200 lines along their declarations, names what each region declares, and gives every behaviour of the grid map its line ranges, so a grid change starts from one table instead of a chain of greps. `scripts/region-index.mjs` renders it at the commit the architecture map pins, and `node scripts/architecture.mjs` rewrites it on every re-pin, so ordinary edits to the two files never touch it; `node scripts/region-index.mjs --now` prints the same tables for a working tree. `test/region-index.test.mjs` fails when the page drifts from what the script renders at the pin, when a region runs past 200 lines, or when a file in `bin/`, `src/` or `public/` is missing from the repo map (Issue #1589).
