- A table view can show as a **List** (View menu, **Layout: Table · List**): the same rows, filters, sorting and density, each row drawn as the table's Chip. The new **Group** button sets up to three ordered levels (select, workflow, toggle, checkbox, link or date by grain), each headed by a label or, for a link, the linked row's Chip, in option, table or A to Z order; every group folds. **Completed by** draws a checkbox field on each row and moves ticked rows to a folded **Completed · N** group; **Nest by** indents rows under a Parent link, with **Tab** / **Shift+Tab** and sideways drags. With no sort, drag sets a manual order saved in the view; a sort orders rows inside each group. Each innermost group ends in an add row that fills every group value and equals-filter and reads a typed date. The footer reads `3 of 8 to-dos · 1 completed`. All of it saves into the view and reaches agents through `weave_table_view` (`layout`, `group`, `completedBy`, `nest`, `collapsed`, `order`), the CLI and REST; the Workspace/Views row gains Layout and Group (Feature #276).
