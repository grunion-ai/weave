- An HTML file on a record now renders inline by default, one frame per file in a many-file field too, sized to its own content height: a long page grows the frame instead of scrolling inside it, and a short page shrinks it. The `?view` response adds one inline script after the doctype that posts the page height to the parent; weave sizes a frame only from messages whose source is that frame's own window, and the page keeps its sandbox with no access to weave's origin. The stored file bytes are unchanged (Issue #1175).
