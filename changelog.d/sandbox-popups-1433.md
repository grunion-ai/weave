- A window that an uploaded HTML file, a document page or a deck opens with `window.open` now stays inside the sandbox (Issue #1433). The sandbox no longer carries `allow-popups-to-escape-sandbox`, so the new window gets an opaque origin and cannot read the storage or cookies of the site it loads. A link you click in a previewed HTML file still opens in a new tab as a normal page: the frame hands the address to weave, and weave opens it when it is http or https.
