- **A lookup of a relation shows the far row's chip** (Issue #643): a lookup whose target field is a relation, such as CRM/Activities.Company reading the contact's Company, answered the company's uuid list in `fields`, the grid, the entity page, CSV and MCP. It now carries the relation's shape, `{id, publicId, name, db}` with the row's chip, and a list of them when either hop is to-many, each far row once; `relations: 'chip'` sends the summary once in `chips` and the grid grafts it back. The grid and the entity page draw the same chip the relation column draws, `select`, `where`, formulas and CSV read the name, and `raw` keeps the ids. A template copied with Use Template keeps it. The Handbook's lookup page says so, and no longer says a to-many lookup takes the first match.
