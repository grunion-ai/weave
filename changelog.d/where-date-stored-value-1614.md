- A `where` on a date field compares the stored date, as sorting and the handbook already promised. `=`, `!=`, `in`, `<`, `<=`, `>` and `>=` read the ISO value on every costume and grain, so `[["Due", "<", "2026-10-01"]]` answers the rows due before October instead of none; it used to compare the field's reading, such as `Jan 5, 2026`, with the caller's ISO string, and only a field configured `format: 'iso'` filtered correctly. A daterange compares its stored bounds. `contains`, `is-empty` and `not-empty` still read the reading (Issue #1614).
