- **The release tag is the hosted deploy** (Issue #478, Feature #250): CLAUDE.md, AGENTS.md rule 7, DEVELOPMENT.md rule 8 and the "Deploy: Railway" guide now say plainly that a host running `weave supervise` with `WEAVE_AUTO_UPDATE=1` is never redeployed to ship a landing. A platform redeploy restarts the container, fails requests for up to a minute and resets the supervisor; it is kept for a Node version, `Dockerfile` or `src/supervisor.js` change. A fix reaches the host with the next release tag, and the guide says to turn off GitHub automatic deploys on the service.
