- An attachment upload can be paused and resumed from its tile, and Retry after a dropped connection sends only the bytes the server does not hold yet (Feature #383). On a workspace that keeps files on disk, the server keeps the bytes that arrived, `HEAD /api/uploads` answers how many it holds, and a `PUT` with an `Upload-Offset` header appends the rest. A `PUT` without that header keeps the one-shot behaviour, so agents and MCP clients see no change.
