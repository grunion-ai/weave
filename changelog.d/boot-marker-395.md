- **The home boot no longer waits on a second schema build** (Issue #395): the page shell now carries `<meta name="weave-workspace" content="<name>" data-root="true|false">`, so the app knows at boot whether it is on the root. The root, including `/w/<root>/`, reads its schema once instead of also fetching `/api/schema` as a registry it would throw away; a member still reads the root registry beside its own schema (the Issue #258 guard). `/health` and the home's `/workspace`, `/workspaces` and `/invites` reads now start beside the schema instead of after it. A shell without the marker falls back to the old speculative registry read. Gate: `test/schema-fetch-browser.test.mjs`, `test/workspaces.test.mjs`.
