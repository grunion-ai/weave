- **The audit log names the real caller** (Issue #495): a request with a token or session records its account and the `x-weave-actor` header is ignored, even when another request names itself while the first one waits on billing; an anonymous caller on a workspace or hub that holds any account is recorded as `anonymous` and its comments carry `anonymous` as author. On a hub with no accounts an anonymous caller still names itself through `x-weave-actor`, as local agents and the CLI do. CSV import, JSON export, JSON import and workspace create, trash, restore and delete each write one audit entry (`csv-imported`, `workspace-exported`, `workspace-imported`, `workspace-created`, `workspace-trashed`, `workspace-restored`, `workspace-deleted`).
