- The render and query-volume budgets join the vitals and feedback budgets in the trend lane, so no PR gate and no main CI gate times a page or a query on a shared runner any more. `budgets.yml` runs all four on every main push and keeps each run's readings (the fastest of its walks, its budget and every walk) as a `trend-series` artifact that the next runs read back (Issue #1709).
- A budget miss no longer turns the budgets run red. It writes a warning on the run and a trend note on the tracker: one standing Issue row per suite and key, written when a run of misses starts and again when it lasts three main pushes, which also sends the alert line. The run goes red only when the lane itself breaks: a suite that read nothing, a failing test that no miss explains, or a failed exit with no failing test (Issue #1709).
