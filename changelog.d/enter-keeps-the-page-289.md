- **Enter in a long document leaves the page where it is** (Issue #289): pressing Enter in the first paragraph of an 80-paragraph Description sent the pane to the end of the document (0 to 2,810px on a 1280x700 viewport), and the next keystroke animated it back over about 900ms; a `/` typed into that animation opened the slash menu and the animation's first scroll event shut it again. Enter now pins the pane where the caret already was: a move of more than 120px within a second of the keypress is put back instantly, as long as the caret was in view when Enter was pressed. The slash menu also owns its own close, so a scroll the reader did not start (no key, pointer, wheel or touch since the menu opened) no longer hides it in the first second, while Escape, a pick and a reader's scroll still close it. Issue #137's wheel contract and Issue #455's slash-line conversion keep their cases. Tests in `test/slash-commands.test.mjs`.
