Loopback names (`127.0.0.1`, `localhost`, `[::1]`, any port), the host of `WEAVE_ORIGIN` and the names in the new comma-separated `WEAVE_ALLOWED_HOSTS` answer; `/api/health` answers any Host so platform probes keep working. A server bound off loopback with neither variable set keeps answering any Host and prints one warning line at startup. Gate: `test/security/host-allowlist.test.mjs`.
