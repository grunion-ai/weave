- **A write from another site is a 403** (Issue #486): any page could send a `text/plain` POST (a request with no preflight) to a weave instance and create, edit or delete rows. A POST, PUT, PATCH or DELETE is now refused when its `Origin` is neither the request's own origin, `WEAVE_ORIGIN`, nor a loopback origin on the server's port, or when it carries `Sec-Fetch-Site: cross-site`. A request with no `Origin` (curl, the CLI, agents) is served as before. With an `Origin` present, a JSON route also refuses a body whose Content-Type is not `application/json`. Gate: `test/security/cross-site-writes.test.mjs`.
