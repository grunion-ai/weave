- **`weave serve` closes every workspace before it exits** (Issue #1661): SIGTERM, SIGINT (Ctrl-C) and a closed supervisor channel used to end the process with each workspace still open, so SQLite never folded the WAL into the `.db`, the `-wal` and `-shm` files stayed, and a copy of the `.db` alone missed every row since the last checkpoint. The server now stops taking connections, gives requests in flight up to 5 seconds to finish and answers them with `Connection: close`, then closes every workspace it holds and exits 0. Its last log line counts the workspaces it closed and any unfinished request it cut off. A server stopped this way leaves each `.db` whole on its own, with no sidecars beside it.
