- **Hiding a field leaves the grid on the click** (Issue #328): every eye flip waited for its `PATCH`, then a `GET /api/schema`, then a full table query before the switch moved or the column went anywhere. On a loaded host, where each of those calls took seconds, the gesture read as broken. A hide now repaints the rows the grid already holds, one column lighter, before the write goes out: zero reads, and the switch moves on the click in both popovers. The write still queues behind `eyeWrites` in the order the flips were made (Issue #243), and the grid is read back only when the table disagrees with what was painted, which is how a hidden frozen column or a field added elsewhere still settles. A show reads once, as before: it needs the column's values. Measured on a copy of the `uno` workspace, `Agent/Sessions` at 1,791 rows: click to the column leaving the grid drops from 68-153 ms to 19-31 ms, with the PATCH, the schema read and the table query all moved off that path, and a show stays where it was at 61-80 ms.
