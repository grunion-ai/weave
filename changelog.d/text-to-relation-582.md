- **Text becomes a relation** (Issue #582): `weave_update_field {type: "relation", config: {targetDb}}` converts a text column in place, so an agent that typed an account as text beside an Account table can link it without rebuilding. Each value links to the target row of that name (exact, then case-folded; a figure is never read as a public id), a value no row carries is refused by name unless `createMissing: true` makes the row, and a many-to-many conversion splits on commas. The field keeps its id, width and description, the target gains the inverse, and the change rolls back with its values like any other type change. The lane is the API's: the field tray has no target picker, so `TYPE_MIGRATIONS` and its UI mirror are unchanged.
