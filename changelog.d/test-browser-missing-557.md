- **`npm test` fails in seconds when the Playwright browser is missing** (Issue #557): a worktree whose Playwright resolved but whose browser executable was not installed ran the whole unit lane, printed its green `# pass` block, then failed every browser file at launch and, on 2026-09-29, never exited. `scripts/test.mjs` now launches the browser once before either lane when the selection holds a browser suite; when the launch fails it prints `# BROWSER MISSING: <the launch error>` and the `npx playwright install <browser>` line, and exits 1 without starting a lane. Every run now ends with one `# RESULT green|red: unit lane ..., browser lane ...` line, so a first-lane summary can no longer be read as the verdict. Gate: `test/test-runner.test.mjs` (4 new cases, including an end-to-end `npm test` against an empty `PLAYWRIGHT_BROWSERS_PATH` that must exit 1 within 60 s).
