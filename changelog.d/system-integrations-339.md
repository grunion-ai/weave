- **System › Integrations** is a new system table, listed in the sidebar's System group between Users and Activity, for the outside tools a workspace holds an API key for. Each row names a Provider (Fibery or Generic API key) and the one Host its key may reach. The key goes in once through `PUT /api/integrations/<id>/credential` and is tested against that host on save: a Fibery key must return the current user, whose name lands in Connected As. A green test seals it in the keystore and keeps only its last four characters as Key Hint; a red test stores nothing and says why in Health Reason. Replacing a key keeps the old one until the new one tests green, changing Host or Provider deletes it, and deleting the row deletes it. No route, MCP tool, export, share link, Activity entry or audit entry reads it back: the keystore API refuses every `integration:` name. (Feature #339)
