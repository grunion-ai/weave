- **A self-update no longer stalls requests while the new release settles** (Issue #607): the first live swap on weave.grunion.ai (v0.4.57 to v0.4.58, 07:02Z on 2026-10-03) left every request unanswered for about ten seconds after the switch, because settling the new worker's deferred open rewrote every entity row and search entry of each workspace, synchronously, in the worker that had just started serving. Settling now writes only what the open changed: a held save keeps its dirty set and a plain save is exact. `#migrate` marks every entity it changes and no longer forces a full rewrite, so an ordinary open that repairs something writes only that too. Gate: `test/supervisor.test.mjs` (41 rows rewritten before, only the repaired table's registry row after).
