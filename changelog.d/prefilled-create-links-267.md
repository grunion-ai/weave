- Prefilled create links: `/t/<table id>/new?<Field>=<value>&…` opens a table's new-row form with those fields set, and nothing is saved until Save. Selects match by option name and relations by the target row's Name; an unknown or computed field is left out and named in a notice, as is a value that resolves to nothing. **Copy create link** in the table menu and in the form builds one. A signed-out visit now keeps its query string through sign-in, so the link lands on the filled form after Clerk; values are capped so the link fits the sign-in hop (Feature #267).
