- **weave installs from a Claude Code plugin marketplace** (Feature #340): the repository now carries `.claude-plugin/marketplace.json` with one `weave` plugin whose `.mcp.json` points at `https://weave.grunion.ai/mcp` over HTTP, so `/plugin install weave --marketplace grunion-ai/weave` connects Claude Code and signs in through Clerk on first use. The plugin carries no version, so Claude Code follows the repository commit and no release has to restamp it. No `.mcp.json` sits at the repo root, so a session developing weave is never wired to production. README names the install line. Gate: `test/claude-plugin.test.mjs`.
