- **Board layout: kanban columns and a picture gallery in one table layout** (Feature #352): a view takes `layout: 'board'` beside Table and List, with `groups` (`stacked` sections or `side` columns, default `side`) and `picture` (`off`, `small`, `medium` or `large`, default the cover field's size; cards 132/188/256 px, columns 184/232/288 px, three small cards per row on a phone). The picture is the record's cover, the first shown attachments field set to Show as cover, through one `coverOf(db, entity)` in `public/board-core.js` that the record page now shares. The View menu shows Board with Columns and Gallery presets and Groups and Picture controls. Cards drag with `RO().sortable`: into another group sets its value with Undo, within a group or with no groups saves the view's order in reading order, and a sort turns hand order off with a Manual button in the footer. Card fields edit through the table cell editor, and a card click opens the record in the pane row with the open card outlined. A query that names an attachments field now returns that field's files. `weave_table_view`, `weave table view --groups --picture`, the schema document and the Views registry (Groups, Picture) carry the new keys. Gates: `test/board-layout.test.mjs`, `test/board-layout-browser.test.mjs`.
