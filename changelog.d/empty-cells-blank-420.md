- **An empty grid cell at rest is blank** (Issue #420): Kyle, 2026-09-26, "make empty cells blank to cut noise". Every empty cell drew a hint, so a table with many empty cells read as a wall of repeated text: "Add description…" in a dashed pill, the date box's "today, 15 sep, 9/15/26…" placeholder (clipped mid-glyph), a grey "—" chip for an unset select, state, lookup or rollup, a dashed "+" for an empty multi-select, file or document chip. Each of those now carries `is-empty` (or is already `.k-add` / `.k-empty`), and one rule in style.css paints them at opacity 0, and every placeholder transparent, in a grid cell that holds neither the focus nor a focused control. Focus the cell and the hint is back; the invisible chip is still the click target that opens its picker. This supersedes the 2026-08-24 chip ruling "empty is dashed, never dimmed" for grid cells at rest. The entity page, footers, stat tiles and activity logs keep their marks: a dash there means no value was computed. Tests: `test/empty-cells-browser.test.mjs` (new: a row with every field empty shows no text, placeholder or dashed outline at rest in both themes; the focused cell shows its hint and the cell it left goes blank; a click on an empty select cell opens the picker); `test/grid-chrome.test.mjs` now pins the empty description as blank at rest and dashed on focus.
