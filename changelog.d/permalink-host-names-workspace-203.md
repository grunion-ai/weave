- A row, table or space permalink no longer carries `/w/<workspace>`: `url` is `/e/<uuid>`, `/t/<uuid>` or `/s/<uuid>` on every door, and the ⧉ buttons copy the same. A workspace host such as `net.weave.grunion.ai` already names the workspace. Anywhere else, a bare link opens in whichever workspace holds it: the server answers `302` to `/w/<holder>/…`, or `301` to the holder's own host when workspace hosts are on. Renaming a workspace no longer breaks links, and links already shared with `/w/` keep working (Feature #203).
