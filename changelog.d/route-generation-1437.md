- A table whose rows arrive after you have moved on no longer paints over the page you opened. `showDatabase` takes the navigation generation the record page has carried since Issue #1444, and a render that no longer owns it drops its paint instead of replacing `#main`. The same generation now decides whether a render may paint the route error card or cancel the pending skeleton, so a failure on the page you left cannot land on the one you are reading. A route that waits on a slow read no longer holds the next one back either: navigations run as they arrive, so opening a row while its table is still loading lands on the row (Issue #1437).
