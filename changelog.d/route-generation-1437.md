- A table whose rows arrive after you have moved on no longer paints over the page you opened. `showDatabase` takes the navigation generation the record page has carried since Issue #1444, and a render that no longer owns it drops its paint instead of replacing `#main`. A route that waits on a slow read no longer holds the next one back either: navigations run as they arrive and the generation decides which one paints, so opening a row while its table is still loading lands on the row (Issue #1437).
