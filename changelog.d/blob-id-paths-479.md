- **File and logo ids stay inside `files/`** (Issue #479): a file id, logo id or `fileBlobs` key in an imported workspace was joined onto the `files/` directory unchecked, so an id holding `../` wrote the import's bytes outside the data directory and read any reachable file back through export, the file routes and `weave_files`. `#blobPath` now accepts only the uuid shape the engine mints and checks the resolved path sits inside `files/`, and `importJSON` refuses a dump carrying any other id before it changes the workspace.
