- **weave tells you when a newer release is out** (Issue #253): `weave serve` asks GitHub for the latest published release of grunion-ai/weave at most once a day, with one unauthenticated request and no token, and keeps the answer in `update-check.json` beside the workspace so a restart inside the day asks nothing. `/api/health` carries `latestRelease`, `releaseCheckedAt` and `releaseBehind` beside `latestSha` and `behind`, which keep their meaning. A newer release turns the sidebar instance chip amber with `v<version> available`, and a toast says so once per release. It works on a plain clone and on a source zip, which the commit comparison never reached. Offline, rate-limited or given a malformed answer, the check stays silent and reports nothing as newer. `WEAVE_UPDATE_CHECK=off` makes no request at all; the Handbook's Environment reference, the `Dockerfile` and `compose.yaml` list it. Kyle decided on 2026-09-28 that the running app makes this call.
