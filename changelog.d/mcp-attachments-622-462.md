- **Attachments in a query select** (Issue #622): `weave_query` with a `select` naming an attachments field returned `(missing)` for every row, even when the file was there, because the select path resolved the value without its row. It now names the file the way the record does, and still marks a file whose bytes are gone as `name (missing)`.
- **Imports name files without bytes** (Issue #462): `importJSON` now returns `{ files, missing }`, listing every attachment that arrived as a name with no bytes, with a `warning` when any did. `weave_import_json`, `POST /api/import` and `weave import` all return it. The MCP `weave_export_json` dump leaves the bytes out by design (Issue #121), so importing it into a fresh data directory used to produce the Issue #250 rows in silence. A dump imported back where its bytes already sit reports nothing missing.
