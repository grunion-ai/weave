- weave's own pages now enforce `frame-src`, `object-src 'none'`, `base-uri 'self'` and `form-action 'self'` beside `frame-ancestors`, so a document opened in the app can no longer frame another site, embed a plugin, move the page's base URL or post a form elsewhere. Frames still load from weave itself, from Cloudflare's bot check and Clerk's fraud check, which Clerk sign-up shows, and from Stripe, which runs Clerk's checkout. Every other directive stays report-only. Browsers send violations of both policies to `POST /csp-report`, which reads at most 16 KiB per report and counts each one by directive, blocked apart from reported; the server logs the 1st, 10th, 100th and each later power of ten. `GET /_supervisor/csp` with the deploy token reads the count since the server started. A page that brings its own sandbox policy, such as a document page or an HTML attachment, keeps that policy and no longer carries the report-only copy (Issue #1637).
