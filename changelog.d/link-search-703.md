- Linking a relation opens the ⌘K search scoped to the relation's target tables instead of a Name-only list: it matches any text on the row, shows linked rows checked, replaces a to-one value on pick, toggles a to-many set until `Esc` or `Return` on an empty box, and ends with `+ New <term>`. `+ Link existing`, the relation editor in the grid and on the record, and the selection bar's `Link to…` all use it, and none preloads the target table. `GET /api/search` takes `tables=<id,...>` (Issue #703).
