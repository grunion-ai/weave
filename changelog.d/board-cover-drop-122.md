- **Drop a picture on a Board card to set its cover** (Feature #353): a desktop file dragged over a card lights it with `is-file-drop`, and the drop uploads the first picture into the row's cover field through the attachments editor's own upload path, then repaints the card. A file that is no PNG, JPEG, GIF or WebP is refused with a toast naming it, and a table with no cover field offers **Add a Photo field**, which adds a single-file cover field and uploads the picture into it. An upload into a single-file attachments field that already holds a file now replaces it, keeping the old file in the row's ledger, where it used to fail with "holds one file". Gates: `test/board-cover-drop.test.mjs`, `test/board-cover-drop-browser.test.mjs`.
