- Table search is saved with the view, beside its filter and sort. Typing in the toolbar box writes the view's `search` after the usual pause; opening the view or reloading brings back the box text and the matching rows, which the server finds through the query's `search`. Duplicate copies the search, a view started from **+ Add view** or reset to the defaults has none, and clearing the box writes an empty search. The raw Blank table still searches without writing. `weave_table_view`, `weave table view --search`, `/api/tables/:table/views/:view` and the **Workspace/Views** row's new **Search** column read and write it, and schema documents carry it (Feature #307).
