- `/start` is a setup page: a left pane walks a new person through Account, Workspace, Template and Agent, and the right pane shows the weave brand and weaves each table in while the workspace builds. Skip setup on any step makes an empty workspace; Set it up myself skips the guided setup straight after sign-in. Sign-in failures come back to the pane with the reason instead of a refusal page. A workspace made here counts as onboarded, so the in-app welcome no longer asks for its name again (Feature #324, Issues #569, #911).
- `WEAVE_OPEN_SIGNUP=1` lets anyone who signs in create workspaces from `/start`, up to `WEAVE_SIGNUP_LIMIT` each (default 1). Without it the page tells a stranger the server is invite only, where it used to end in a 403.
- The Agent step lists chat apps first (Claude, ChatGPT, Gemini, Perplexity), then Cursor, VS Code, Claude Code and any remote MCP client, each with its own steps, the workspace MCP address and a first message to paste, both with copy buttons. It turns green when that app first reaches the workspace over OAuth MCP and passes only connected or skipped (Feature #326).
- `test/setup-flows-browser.test.mjs` walks every setup path in the CI gate that holds production releases, and connects a simulated chat app through protected-resource discovery, dynamic client registration, PKCE and the token exchange, the way claude.ai and ChatGPT do.
