- **Button sizes from one table** (Feature #387): six steps, 20, 24, 28, 32, 44 and 52 px, each with its padding, icon size, gap, font size and radius, live in `public/button-sizes.js` and as `--wv-btn-*` tokens in `style.css`. A Tabler `.btn` takes the 32 px step and `.btn-sm` the 28 px step through Tabler's own variables, and `.wv-btn-*` classes size the rest. Every icon button in a view header is now 28 px with a 16 px glyph, Copy permalink included (Issue #1865), the bug button is 28 px, and the phone header and bottom bar take the 44 and 52 px steps. DESIGN.md has a Buttons section. A source test ratchets the raw button sizing left in `style.css` (75 to 32), and a browser sweep fails on a button that matches no row.
