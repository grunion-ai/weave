- **Every editable text field shares one focus treatment** (Issue #1030): the view title, record name, grid cells and field rows, the view rename input, the nav add-table input and the description editor each painted their own focus, and the view title drew two outlines (its grey border plus the global `:focus-visible` outline, which is `!important`). All six now carry `.wv-edit`: transparent at rest, a faint border on hover, and on focus the surface background with one `inset 0 0 0 1.5px` primary ring and no outline. Padding and size come from `--wv-edit-pad` and `--wv-edit-fs` (renamed from `--wv-inline-*`), so each field keeps its type size. An empty title or record name shows "Untitled" and holds at least 8ch, the view title row keeps an 8px gap with or without a description, the title pulls left only when nothing precedes it, and the description info button sits as a 14px superscript glyph at the title's top right, with a 24px hit area (44px on touch) that starts at the title's edge, extends right and down, and leaves the row height and the title's own tap area alone.
