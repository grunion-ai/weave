- **Hovering a truncated grid chip shows its whole value** (Issue #584): since Issue #423 a value too long for its column ends in an ellipsis inside the chip, and the label span carried the value as its title, but the chip itself kept the field name ("Program"), so hovering the chip's padding showed the field name. The title now sits on the chip: a cut chip carries the value, a chip that fits keeps the title it was drawn with (the field name on a select and a state, none on a multi chip). A column resize rechecks it, in a registry grid as well as a view. Gate: `test/chip-ellipsis-browser.test.mjs` (select, state, multi and key chips in both themes, a short select keeping "Program", and a widened column handing the field name back).
