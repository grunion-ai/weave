- **A table with no term of its own says record, not row.** New tables read "+ New record" and "Search records", and every surface that names the thing itself says record. Row stays the word for grid geometry (row density, the Σ row, a CSV header row), and a table can still pick Row as its term. A `weave_build` table takes `records`; `rows` keeps working. This reverses the default set in Issue #618.
