- **Migrate to weave cloud** (Feature #316): `POST /api/workspaces` with `{ name, from: "backup:<archive>", key }` creates a cloud workspace from an archive the caller's account stored, decrypting it in a scratch directory with the supplied passphrase and running the existing restore. The key is never stored or logged. A wrong key answers 400, another account's archive 404, and a second migration of the same archive 409. `weave workspace migrate --from weave://<host>/<account>[/<archive>]` is the CLI form.
