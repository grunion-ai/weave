- Removing a file, a logo or a purged row in one workspace no longer deletes bytes that another workspace in the same data directory still names. Every workspace shares one `files/` folder, and importing one workspace's export into another keeps the file ids, so a delete in the copy used to take the original's file with it and the original answered "File blob missing". The bytes now go only when no workspace in the data directory names the file. (Issue #1359)
