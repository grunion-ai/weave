- **A built row is one write** (Issue #681): `weave_build` created each row, fired its on-create automations, and only then linked its relation values, so a template reading `{{Font}}` rendered blank. The build now creates rows table by table in relation order (a table's rows after the rows they point at) and writes every relation value that resolves inside the create, so an automation sees the row whole. Only a reference the build cannot resolve yet (a cycle, or a later row of the same table) is still linked after. A `{{Field}}` placeholder that resolves to nothing now reads `(no Field)` rather than leaving a gap. `test/build.test.mjs` builds a Review row before the Font it names.
