- **MCP injection measurement harness** (Issue #499): `security/mcp-inject/` seeds a scratch workspace with one row carrying a planted instruction, runs a headless agent with an ordinary task over weave's MCP server, and judges whether the instruction was carried out. It is run by hand, costs model calls, and is not part of `npm test`; `test/security/mcp-inject.test.mjs` covers the grid, the seed, the judge and the transcript reader without calling a model.
