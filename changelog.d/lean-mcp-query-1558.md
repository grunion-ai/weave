- `weave_query` over MCP answers lean rows by default: id, public id, name, revision and the value fields, with a relation as `{id, publicId, name}`. Documents, the Chip and Card views, raw values and the chips map stay out, so a 200-row page of the weave Issue table is 67 KB where it was 3.2 MB. `shape: 'full'` returns the whole envelope as before, and `shape: 'row'` the list row it was. One call reads at most 2,000 rows: a larger limit or `limit: -1` is refused with the paged read named, and a limit or offset sent as a numeric string is read as a number. REST and the CLI answer as they did (Issue #1558).
