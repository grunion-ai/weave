- **Docker on the first screen, a GHCR image on every tag, and the Official MCP Registry** (Feature #292): the README Quickstart shows `docker compose up -d` beside the node one-liner, and its lead names the hosted instance at https://weave.grunion.ai as the same code behind a sign-in door. `.github/workflows/publish-image.yml` builds the Dockerfile on every `v*` tag and pushes `ghcr.io/grunion-ai/weave:<version>` and `:latest`, labelled `io.modelcontextprotocol.server.name=io.github.grunion-ai/weave`; a `workflow_dispatch` run builds without pushing. `server.json` lists weave in the Official MCP Registry as that OCI package over stdio, and the same workflow publishes it with a pinned `mcp-publisher` signed in through GitHub OIDC. `scripts/validate-server-json.mjs` checks the file against the registry schema with no dependency, and the release fold stamps the package version into it.
