- **The Quality mirror carries each case's last result and syncs over HTTP** (Issue #1244, Issue #1245): the CI reporter now records a pass or fail per test, and each shard result carries them. `src/quality-mirror.js` plans the sync as a list of writes: a case red on every attempt reads Failing, red then green on a retry reads Flaky, green reads Passing, and a case no run names takes its file's result when the file is green. `scripts/quality-sync.mjs --from <tracker> --token-env <name> --results <dir>` applies that plan to a tracker over HTTP, removes suites whose file is gone, and fails when drift is left after the sync; `--check` reports the drift and writes nothing. Gates: `test/quality-mirror.test.mjs`, `test/quality-sync.test.mjs`.
