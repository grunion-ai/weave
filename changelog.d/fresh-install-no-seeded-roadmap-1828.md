- **A fresh install no longer ships weave's own v0.1 to v0.3 roadmap** (Issue #1828): `seedWeaver` wrote 4 Issue rows and 18 Feature rows describing weave's own early history, so anyone who opened Development on a new instance read a roadmap that stopped at v0.3 with nothing marking it as a partial, frozen excerpt. The seed now creates the Issue, Feature and Release tables with their fields and leaves them empty, so a bug report on that instance still files and the Development space home sends the reader to the live tracker. A server that keeps a read copy fills the same tables from `docs/development.json`, which carries every one of those 22 rows at its current state rather than the state frozen into the seed.
