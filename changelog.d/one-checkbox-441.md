- **One checkbox, and a Fields popover that drags and fits** (fixes Issues #441, #384, #445, #446): the grid's row selector, the Fields popover, the Filters popover and the field dialog all draw weave's one checkbox, `input.form-check-input`, so each computes the same 16px box, 4px radius, border and checked fill in both themes; the hand-drawn `.field-visible-check` and its `role="switch"` are gone, and each Fields row, Deleted rows, the Σ rollup row and each filter option is a real, labelled checkbox that Space flips. A field dialog checkbox sits on its label's first line everywhere, not over it, and the Literal hint sets its syntax as code. A Fields row reads `grab` at rest over its name and its grip, never an I-beam; a press that moves drags it (the Views list shares the same drag), the cursor reads `grabbing` wherever the pointer goes until the drop, Escape or a cancelled pointer, no text selects, and one square-ended line marks the gap. The Fields popover grows to the room below its button before its list scrolls, its header stays outside the scroll box, and a scrolled list snaps so no row sits half under the top.
