- **The workspace rail and sidebar hold one left edge on every view** (Issue #546): Tabler's `:root { margin-left: calc(100vw - 100%) }` (at 992px and wider) pushed the whole page right by the width of a classic scrollbar, so in Safari with a mouse attached the rail and sidebar sat 16px further in on a table that scrolls the page (a long Issue or Release table) than on one that does not (a short table, a space landing). `style.css` now sets `:root { margin-left: 0 }`; weave is left-anchored and has no centred page to keep still. The browser harness gains an `engine` option so a suite can pin WebKit. Gate: `test/ws-rail-inset-browser.test.mjs`.
