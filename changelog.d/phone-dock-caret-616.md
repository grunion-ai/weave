- **End reaches the end of a code line on the phone dock** (Issue #616): the phone dock sheet no longer sets `overscroll-behavior: contain`. In Chromium that property on the scroll container stops End from moving the caret inside a document's code block, so the caret stayed at the `CODE` element's offset 0 and typed text landed at the start of the line instead of its end (` // hiconst x = 1;` for `const x = 1;`). `#main` and the desktop dock already leave the property off for the same reason (Issue #609), and since #609 the document no longer scrolls, so the sheet's scroll has nothing left to chain into. Gate: a 390x844 dock case in `test/code-raw-toggle-browser.test.mjs`.
