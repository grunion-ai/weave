- A new main merge no longer ends or restarts the dev soak, so one fifteen-minute window now reviews a batch of commits. Merges queue behind the running soak and the next window takes the newest commit. A soak whose commit dev moved past during the window keeps its clock and smoke schedule, posts `dev-soak` success naming the commit dev moved to, and stops applying the worker pid check and the requirement that its own watch passes. Each poll checks the release dev serves now for a rollback or a failed watch, and a failure after a move posts pending as superseded with no alert, leaving the queued soak to catch it.
