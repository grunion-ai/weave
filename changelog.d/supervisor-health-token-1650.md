- **Anonymous `/api/health` no longer carries the supervisor block** (Issue #1650): on a supervised install every `GET /api/health` told whoever asked the release directory, worker pid, full commit, track, swap history and free disk, though the worker withholds even its version from an anonymous caller. The supervisor now adds its block only to a request whose `X-Weave-Deploy-Token` header matches `WEAVE_DEPLOY_TOKEN`, strips that header before any request reaches the worker, and passes every other health request through untouched. The dev deploy, the dev soak, the production promotion and the fixer's dev check send the header. The promotion's select job holds no secret, so the guard that holds back a pick while prod serves a rollback moves from select into the promote job, which reads health with the token before it moves production. The supervisor change takes effect when `weave supervise` restarts.
