- A workflow state chip now paints the colour its state names. Eight `.k-state.cat-*` tone rules in `public/chip.css` outranked `.hue-*`, so an In progress state coloured green still showed blue in the grid, pickers, search, relation chips, cards and the field dialog. The rules are gone; `.hue-*` is the one source of chip colour, the hue-less filter chip takes its category hue, and the phone applet builds all ten hues from `chip.css` instead of a five-hue copy whose dark values had drifted. A paint contract test (every chip kind, hue and category, both themes, Chromium and WebKit) runs on every pull request, a surface test compares painted colours across eight surfaces, and a CSS lint refuses any other rule that sets `--fill`, `--text` or `--dot`. (Issue #969, Issue #771)
