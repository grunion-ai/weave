- **The loading rope keeps moving while the page is busy** (Issue #390): the rope animated `stroke-dashoffset` with SMIL, which Chrome and Safari run on the main thread, so it froze for every long task during boot or a slow route and then jumped. The app now shows the rope at rest through windows that move by `transform` only, which the browser runs on the compositor. Each end of the old dash is an anchor with a round cap, riding the dash's end frame by frame on the same 2000 ms cycle and easing, and the unweave still ends on the two end dots, so the rope looks as it did. `test/page-loader-browser.test.mjs` forces a 250 ms long task and requires fresh frames inside it.
