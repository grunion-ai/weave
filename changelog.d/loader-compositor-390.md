- **The loading rope keeps moving while the page is busy** (Issue #390): the rope animated `stroke-dashoffset` with SMIL, which Chrome and Safari run on the main thread, so it froze for every long task during boot or a slow route and then jumped. The app now shows the rope at rest inside a window that slides left to right by `transform` while the mark slides back, which the browser runs on the compositor. The window follows the old dash's span frame by frame on the same 2000 ms cycle and easing, so the draw-in, hold and unweave keep their timing. `test/page-loader-browser.test.mjs` forces a 250 ms long task and requires fresh frames inside it.
