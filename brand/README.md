# weave brand

The weave logo mark and its generation pipeline. Selected 2026-08-16 after four
exploration rounds (contact sheets in [docs/](docs/)).

## The mark — "h3"

A horizontal rope: two strands, three crossings, true alternating over-under
weave. Parametric — generated by `rope(n, pitch)` in
[build-logos.mjs](build-logos.mjs) with `n=3, pitch=8`, amplitude 8, strand
width 3.5 on a 48-unit grid. The under-strand is cut with SVG masks
(gap = strand width + 2.5), so every asset is transparent-safe.

| File | Use |
| --- | --- |

| `weave-mark-light.svg` | Mark on light surfaces (blue + ink) |
| `weave-mark-mono-blue.svg` | Canonical one-color mark (print, PDF, stamps) |
| `weave-mark-mono-cream.svg` | One-color on dark surfaces / photography |
| `weave-mark-white.svg` | On blue-filled contexts (buttons, banners) |
| `weave-favicon.svg` | Favicon source (mono, 4.5 strands) |
| `weave-app-icon.svg` | 512 squircle app icon |
| `weave-lockup-dark.svg` / `-light.svg` | Inline mark + wordmark |

`assets/png/` — rasters rendered via headless Chromium: favicon 16/32/48 +
`favicon.ico`, app icon 512/180, mark 256, lockup 512.

## Usage rules

- **Minimum sizes:** mark 12px tall; lockup 80px wide. Below that, use the favicon build.
- **Clear space:** half the rope height (≈ 6 units at 48 scale) on all sides.
- **Never** recolor strands outside the pairs above, outline the mark, or
  rotate the horizontal mark (vertical/diagonal ropes were explored and
  rejected for the primary — see `docs/`).
- The lockup wordmark is Outfit 600; the SVG falls back to the system stack if
  Outfit isn't loaded.

## Rebuilding

```
node brand/build-logos.mjs        # SVGs -> brand/assets/
node brand/render-png.mjs         # PNGs via Playwright Chromium
node --test brand/build-logos.test.mjs
```

ImageMagick cannot rasterize these SVGs (its delegate drops `<mask>`), which is
why raster export goes through a browser engine. `favicon.ico` is packed with
`magick png/favicon-16.png png/favicon-32.png png/favicon-48.png png/favicon.ico`.
