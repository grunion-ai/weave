Today's map draws a target-set relation as one edge per member table, so Showcase's five polymorphic tables (Comments.On, Activity.Subject, Notes.Related, Approvals.Of, Tags.Applied to) collapse into one column of arrows and nothing says that Activity reaches everything, that Comments and Tags share three targets, or that Notes.Related points at structure as well as rows. Plain pairs and target sets look the same.

Four layouts below, each drawn on the live Showcase schema in both themes. The node card is today's card, untouched. Hover a polymorphic source, its field pill, junction or legend chip to light that set; click to pin it. The three unrelated Showcase tables (Formatting, Documents, Icons) are left out of every drawing.

A. Junction node 3 columns

Communicates. A target set is one thing: the junction is the hub and its fan is the membership, so Activity's twelve members read as one node reaching everything and Comments and Tags visibly share Tasks · Docs · Meetings. Costs. Five nodes that are not tables and a third column; the source-side members of Activity (Notes, Comments, Approvals, Tags) have to be reached by curves that double back.

B. Bundled edges tables only

Communicates. One relation is one stroke: the trunk's weight is the set's size and the field name sits on it exactly once, so the eye counts five relations instead of twenty-eight arrows. Costs. Bundling is drawn geometry rather than a layout: every split point is placed by hand-tuned rules, a single member edge is hard to pick out or click, and a hub whose members sit on both sides still loops back.

C. Concentric hub-and-spoke rings

Communicates. Hub-ness by position: the polymorphic tables sit in the centre, everything they reach rings them, structure has its own outer band, and stroke weight says how many kinds of row each set spans. Costs. Space boxes disappear, so the map stops saying "this space holds these tables"; plain pairs keep only ring adjacency; past a dozen tables the angles crowd and Activity's spokes dominate the picture.

D. Matrix companion map + grid

Communicates. The exact record: every relation × every table, cardinality per cell, with the map kept above it only for shape. A shared target is a shared column, and hovering a row lights the same set in the picture. Costs. Two views to keep in step; the grid grows with sources × tables and needs horizontal scroll early; the map on its own is still today's fan of arrows.
